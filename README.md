# Yeni İstanbul A2 - Units 1-2 Persian Learning App

Standalone, offline-capable web app for Persian-speaking learners of Turkish.

## Implemented scope

- Unit 1, `Gezelim Görelim`: kitchen actions, recipes, restaurant ordering, profiles, and two workbook-derived sections from pages 4-10.
- Unit 2, `Haberiniz Olsun`: life events, success, cinema, news and health, plus two workbook-derived sections from pages 11-16.
- Each unit contains 30 selected vocabulary items in six groups of five.
- Every vocabulary group has exactly 22 base exercises; groups 2-6 include five reviews of earlier items.
- Each unit ends with exactly 22 grammar exercises. Unit 2 covers the definite past, past nominal sentences, cause/effect connectors, and `ile`; its final five questions review Unit 1.

Incorrect answers are appended after the base exercise queue and return in another mode when possible. Progress, XP, streaks, daily goals, mastery, due dates, search, Turkish speech, and review stay local to this app.

Open `index.html` through a local web server for full offline/PWA behavior.
